# Third-party notices

The Rust scaffold in [Cargo.toml](Cargo.toml) declares no external crate dependencies.
It uses the Rust standard library supplied by the selected toolchain. No third-party
runtime source is vendored here.

When dependencies are introduced, record their versions, licenses and required notices
here, keep the lockfile, and review provenance before adding them. Existing attribution
in the repository's governance documents remains applicable.
